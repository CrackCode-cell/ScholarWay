# ScholarWay Architecture

ScholarWay is a personalized scholarship discovery and application-tracking platform.

## Main flow

Student Profile
→ Scholarship Discovery
→ Eligibility
→ Personalized Matching
→ Saved Scholarships
→ Application Tracking
→ Dashboard

## Backend

React Native
→ REST API
→ Spring Boot
→ Controller
→ Service
→ Repository
→ JPA / Hibernate
→ PostgreSQL

## Main backend systems

- Student profiles
- Scholarships
- Scholarship requirements
- Eligibility
- Matching
- Saved scholarships
- Applications
- Dashboard
