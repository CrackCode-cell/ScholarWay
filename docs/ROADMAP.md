# ScholarWay Development Roadmap

## Current foundation

- Spring Boot backend
- PostgreSQL database
- JPA / Hibernate persistence
- Scholarship system
- Scholarship requirements
- Student profiles
- Eligibility checking
- Deterministic scholarship matching
- Saved scholarships
- Application tracking
- Dashboard backend
- React Native / Expo frontend
- Frontend API integration

## Next development phase

- Connect matching results to the frontend
- Build the student dashboard UI
- Connect saved scholarship actions
- Connect application tracking to the frontend
- Improve profile editing and loading
- Improve navigation and user experience

## Later development

- Authentication
- DTO-based API responses
- Better validation and error handling
- Real scholarship data
- Financial literacy tools
- Budgeting and financial education
- More advanced personalization
- Notifications and reminders
- Testing
- Deployment

## Long-term goal

Build ScholarWay into a coherent student platform that helps students discover relevant scholarships, understand their potential eligibility, organize applications, and develop stronger financial literacy.
