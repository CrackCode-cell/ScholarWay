# ScholarWay

ScholarWay is a personalized scholarship discovery and student financial-literacy platform designed to help students find relevant scholarships, understand their eligibility, and organize their applications.

## Core User Flow

Student Profile  
→ Scholarship Discovery  
→ Eligibility Checking  
→ Personalized Matching  
→ Saved Scholarships  
→ Application Tracking  
→ Student Dashboard

## Technology Stack

### Frontend
- React Native
- Expo
- TypeScript

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- REST APIs

### Database
- PostgreSQL

## Current Backend Systems

ScholarWay currently includes backend foundations for:

- Scholarship management
- Student profiles
- Scholarship requirements
- Eligibility checking
- Personalized scholarship matching
- Saved scholarships
- Scholarship application tracking
- Student dashboard data

## Matching System

The current matching prototype evaluates several student factors:

- GPA
- Major
- Location
- Financial need
- FAFSA completion
- Activities

The prototype uses a 100-point scoring model to demonstrate how personalized scholarship recommendations can work.

## Project Goal

The long-term goal of ScholarWay is to provide students with a centralized platform for discovering scholarships, understanding their opportunities, tracking applications, and developing stronger financial-literacy skills.

## Development Status

ScholarWay is an active student-built project under development. The current focus is building and understanding the core backend, database, frontend integration, and personalized scholarship workflow before moving toward deployment and advanced features.
